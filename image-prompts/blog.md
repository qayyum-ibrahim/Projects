## How to use
1. Start ONE new ChatGPT chat for this site. Paste the "Style" block first and say: "Remember this style for every image I ask for in this chat."
2. Paste the prompts below one by one in the same chat, so the look stays the same.
3. Download each image and save it as **JPG** with the exact file name shown. Put the files in `site-blog/public/images/`.
4. Keep each file under about 400 KB so the site loads fast.
5. If a result has text, a logo or a strange detail, ask for another try. Add: "no text, no logo, no watermark."
6. Sizes: ask for landscape, portrait or square as shown. Exact pixels can differ. The site crops images to fit.
7. People in these images are fictional. Check faces and hands before you use an image.

## Style (paste this first)

Editorial photography. Muted paper tones, soft natural window light, warm off-white with small brick-red accents, calm and thoughtful, shallow depth of field, realistic. No text, no logos, no watermark.
